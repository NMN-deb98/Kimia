# نقشه‌ی راه کیمیا

اصل پروژه: هر قابلیت فقط وقتی در برنامه ظاهر می‌شود که واقعاً کار کند و روی گوشی‌های معمولی قابل اجرا باشد.

| مرحله | محتوا | معیار تکمیل |
|---|---|---|
| ۱ (این نسخه) | چت محلی، مدیریت مدل، ساخت خودکار APK | APK نصب می‌شود، مدل دانلود و بارگذاری می‌شود، چت پاسخ می‌دهد، بدون اینترنت کار می‌کند |
| ۲ | حافظه با Room، چند گفتگو، جست‌وجو و ویرایش حافظه، قفل برنامه | گفتگوها و حافظه بعد از بستن برنامه می‌مانند؛ قفل با اثر انگشت کار می‌کند |
| ۳ | صوت: Whisper.cpp برای گفتار به متن، TTS سیستم برای خواندن پاسخ | دیکته‌ی فارسی آفلاین؛ پاسخ صوتی |
| ۴ | بینایی: OCR و تحلیل تصویر/اسکرین‌شات | استخراج متن از عکس بدون اینترنت |
| ۵ | ابزارها و AI Core: ابزارهای مرتبط با گوشی (یادآوری، فایل‌ها، اسناد PDF/Word/Excel)، مسیریابی درخواست به ابزار | مدل ابزار را درست انتخاب و اجرا می‌کند |
| ۶ | اینترنت: جست‌وجوی وب و خواندن صفحه، تأیید کاربر برای کارهای حساس | پاسخ با منبع، بدون API پولی |
| ۷ | آموزش، بازی (شطرنج با Stockfish)، همراه شخصی | هر کدام جداگانه قابل استفاده |
| ۸ | تصویر: تولید با stable-diffusion.cpp فقط روی گوشی‌های قوی | فقط وقتی تست روی گوشی واقعی قابل‌قبول باشد |
| ۹ | کلیپ‌سازی با FFmpeg (متحرک‌سازی تصویر، افکت دوربین) | تولید ویدیوی واقعی از تصویر و متن، بدون ادعای «ویدیوی هوش مصنوعی» |

## محدودیت‌های صادقانه
- مدل‌های ۰٫۵ تا ۳ میلیارد پارامتری روی گوشی از Claude و مدل‌های بزرگ ابری خیلی ضعیف‌ترند، به‌خصوص در فارسی.
- تولید ویدیوی هوش مصنوعی (مثل Wan) روی گوشی عملی نیست. تولید تصویر هم فقط روی گوشی‌های قوی و کند ممکن است.
- «کنترل مرورگر» و «Coding Agent» در حد گوشی کار خواهند کرد، نه در حد Claude Code.
