# معماری (مرحله ۱)

- `:aichat` — ماژول موتور. کد JNI و Kotlin از نمونه‌ی رسمی `examples/llama.android` در llama.cpp (نسخه‌ی `b12219`) گرفته شده، با دو اصلاح: خطای بارگذاری کتابخانه‌ی بومی دیگر برنامه را نمی‌بندد، و خطای پردازش پیام کاربر دیگر موتور را گیر نمی‌اندازد. ظرفیت context از ۸۱۹۲ به ۴۰۹۶ کم شده تا روی گوشی‌های ضعیف RAM کمتری بگیرد. خود llama.cpp در مخزن نیست و موقع ساخت (`scripts/fetch-llama.sh`) دانلود می‌شود.
- `:app` — برنامه‌ی Compose.
  - `ChatViewModel`: وضعیت چت، بارگذاری مدل، دانلودها.
  - `data/ModelStore`: دانلود با ادامه (Range)، افزودن از فایل، اعتبارسنجی هدر GGUF.
  - `data/ModelCatalog`: فهرست مدل‌های رسمی و پیشنهاد بر اساس RAM.
  - `data/ConversationStore`: ذخیره‌ی گفتگو (JSON).
  - `ui/*`: صفحه‌ها و تم.
- فقط `arm64-v8a`. موتور CPU به‌صورت `GGML_BACKEND_DL` و `CPU_ALL_VARIANTS` ساخته می‌شود، یعنی در زمان اجرا بهترین نسخه (dotprod، i8mm و ...) برای CPU همان گوشی انتخاب می‌شود.
- مدل در حافظه‌ی بومی می‌ماند؛ ادامه‌ی یک گفتگوی ذخیره‌شده بعد از بستن برنامه، حافظه‌ی مدل را بازیابی نمی‌کند (مرحله ۲).
