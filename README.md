# کیمیا (KIMIA)

دستیار هوش مصنوعی شخصی برای اندروید؛ رایگان، متن‌باز و اجرا روی خود گوشی (بدون سرور و بدون API پولی).

## وضعیت فعلی: مرحله ۱

کار می‌کند:
- چت فارسی (راست‌به‌چپ، حالت تاریک/روشن، فونت وزیرمتن) با مدل زبانی محلی از طریق llama.cpp
- مدیریت مدل: دانلود با قابلیت ادامه، افزودن فایل GGUF دلخواه، حذف، پیشنهاد مدل بر اساس RAM گوشی
- ذخیره‌ی گفتگو روی گوشی
- ساخت خودکار APK با GitHub Actions

هنوز ساخته نشده (در نقشه‌ی راه است، بیرون از این نسخه): صوت، تصویر، مرورگر، حافظه‌ی بلندمدت، برنامه‌نویسی و بقیه. هیچ‌کدام در برنامه به‌صورت الکی نمایش داده نمی‌شوند. جزئیات: `docs/ROADMAP.md`.

## نصب
1. به بخش **Releases** همین مخزن برو و آخرین فایل `KIMIA-build….apk` را روی گوشی دانلود کن.
2. فایل را باز کن و اگر اندروید خواست، نصب از «منبع ناشناس» را برای مرورگر یا مدیر فایل اجازه بده.
3. برنامه را باز کن، از «مدل‌ها» یک مدل دانلود کن (فقط یک بار، ۴۰۰ مگابایت تا ۲ گیگابایت) و شروع کن.

حداقل: اندروید ۹ و گوشی ۶۴بیتی ARM (تقریباً همه‌ی گوشی‌های ۸ سال اخیر).

## ساخت از سورس
GitHub Actions با هر push روی شاخه‌ی `main` APK را می‌سازد (فایل `.github/workflows/build-apk.yml`). برای ساخت محلی: `./scripts/fetch-llama.sh` و بعد `./gradlew :app:assembleRelease` (نیاز به Android SDK و NDK ‏29).

## مجوزها
- llama.cpp: MIT (`LICENSE-llama.cpp`)
- فونت وزیرمتن: SIL OFL (`LICENSE-Vazirmatn-OFL.txt`)
- مجوز هر مدل در صفحه‌ی «مدل‌ها» کنار همان مدل نوشته شده است.

## نکته درباره‌ی امضای APK
کلید امضا (`keystore/kimia-debug.jks`) عمداً در مخزن است تا همه‌ی نسخه‌ها یک امضا داشته باشند و بتوان برنامه را بدون پاک کردن مدل‌ها به‌روز کرد. این برای استفاده‌ی شخصی مناسب است، نه برای انتشار در فروشگاه.
